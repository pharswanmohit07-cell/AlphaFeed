# AlphaFeed

Social trading frontend for discovering traders, strategies, and copy-trading opportunities.

## Stack
- React
- TypeScript
- Vite
- Tailwind CSS
- Lucide React

## Frontend scope
This first commit is intentionally frontend-only. It establishes the visual system, core layout, reusable UI, and mock data. Monad, Kuru, Solidity, Chainlink CRE, backend APIs, and Hunyuan will be integrated later behind typed interfaces.

## Run locally
```bash
npm install
npm run dev
```
